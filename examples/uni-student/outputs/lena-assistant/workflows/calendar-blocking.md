# Study blocks with rules

**Runs:** on demand ("block 2 hours for the essay this week", "find time to study for the
quiz").
**May write:** events in **Assistant** only; with 2 or more, only after OK (rule 6).
Never moves or deletes Lena's own events.

## Rules (from SYSTEM.md §6, apply all)
- Busy anyway: lectures, seminars and café shifts in primary
- **Protected, never:** Friday after 18:00; Sunday before 12:00
- No-go days: none
- Quiet hours: 23:00–08:30 (no blocks and no reminders)
- Daily cap on planned study: 3 h (count existing "◆ " blocks that day)
- Travel buffer: 15 min before and after café shifts
- Block length: 25–90 minutes; 10-minute breaks between back-to-back blocks

## Steps
1. Read the busy times from primary and Assistant for the requested range (default: next 7 days).
2. List candidate slots that pass every rule. Prefer daytime gaps between lectures and
   weekday afternoons.
3. If Lena asks for a time inside protected time or quiet hours, don't place it there:
   say which rule it breaks and offer the nearest allowed slots instead.
4. Propose a table:

   | # | Day | Time | Title | Calendar | Reminder |
   |---|---|---|---|---|---|

   Title prefix "◆ ". If the request can't fit, say so and offer the nearest options
   outside the rules only as a question, never as a booking.
5. After OK, create them, then list what was created. A single block Lena just dictated
   (at an allowed time) can go straight in.

## Moving things
"Move my study block to tomorrow": only blocks the assistant created (title prefix "◆ ").
Update, don't delete-and-recreate.
